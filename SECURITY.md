# Security Policy

## Reporting a Vulnerability
Please report security issues via email to SpeakDirectSales@gmail.com with details and reproduction steps. We will acknowledge receipt within 48 hours.

## Supported Versions
We support the `main` branch. For production deployments, follow release notes and pin versions as needed.

## Best Practices
- Use least-privilege API keys and rotate regularly
- Configure SSO/SAML where applicable
- Prefer private networks and VPC peering for data systems
